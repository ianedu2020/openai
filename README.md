# Neon Breach (FPS 프로토타입)

요청하신 "베스트셀러가 될 만한 FPS" 방향으로, **즉시 실행 가능한 1인칭 슈팅 웹 프로토타입**을 만들었습니다.

## 핵심 컨셉
- 빠른 템포 + 짧은 세션(90초)
- 명확한 목표(드론 파괴로 점수 획득)
- 낮은 진입장벽(브라우저에서 즉시 실행)

## 실행 방법
```bash
python3 -m http.server 4173
```
브라우저에서 `http://localhost:4173` 접속 후 **게임 시작** 버튼을 누르면 플레이됩니다.

## 조작
- `W/A/S/D`: 이동
- `마우스`: 시점
- `좌클릭`: 사격
- `Shift`: 대시

## 베스트셀러 확장 아이디어
1. 메타 진행(무기 해금, 스킬 트리, 캐릭터 빌드)
2. 2~4인 코옵 모드 + 주간 챌린지
3. 리플레이 공유/랭킹/스트리머 모드
4. 시즌 이벤트(맵 변형, 보스 레이드)
5. 모바일/패드 크로스플랫폼 지원
